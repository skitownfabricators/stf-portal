# STF Portal (front end)

Pages for Ski Town Fabricators clients and shop, served by GitHub Pages at
https://skitownfabricators.github.io/stf-portal/

- Each person opens their own private link (`?k=...`). No Claude or Google login.
- This repo holds only the page. All data (requests, photos, links) stays in the
  skitownfabricators Google Drive, behind the STF Portal Apps Script (`config.js` has its address).
- No tokens, client data or job files are ever committed here. The repo is public.
- Built by FAB - Apps from `portal-gas/build.py`. Do not edit `index.html` by hand.
